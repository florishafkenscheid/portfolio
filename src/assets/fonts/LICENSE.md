Static instances cut from the variable fonts in https://github.com/google/fonts
(Fraunces, Geist, JetBrains Mono), all under the SIL Open Font License 1.1.
Used only to render Open Graph preview images (Satori needs static TTFs).

Geist-Regular.ttf has its GPOS table removed: Satori misapplies Geist's
kerning and renders uneven word gaps.
